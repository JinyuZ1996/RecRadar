## 英文期刊

从论文的主要贡献开始选刊。下列入口用于缩小阅读范围，同一本期刊可能适合多个方向。确定候选后，可用英文刊名查阅办刊范围（Aims & Scope），再对照近期同类论文。

| 论文的主要贡献 | 可先查阅的期刊 |
| --- | --- |
| 推荐模型、个性化排序与信息检索 | TORS、TOIS、IPM |
| 图推荐、交互序列挖掘与知识发现 | TKDE、TKDD、DMKD |
| 多模态推荐与内容理解 | TMM、TOMM、Information Fusion |
| 具有通用性的学习方法与模式识别 | TPAMI、TNNLS、Neural Networks、Pattern Recognition |
| 人机交互、用户决策与社会计算 | TIIS、DSS、TCSS |

我们沿用原表的两组分类。主表并排展示选刊常用指标，展开每组下方的明细可查 JCAR 和历次变化。审稿时间为经验区间，原表未统一标注首轮决定或全程耗时。

## 数据来源与纠错

基础数据来自我们整理的《领域期刊及会议整理》2026-11-01 版。我们以往届会议论文集或期刊已发表的推荐系统论文作为收录依据。整理会议日期时，我们优先查阅当届 CFP（征稿启事）或 Important Dates 页面，并用聚合网站交叉核对。我们计划在每月 1 日（UTC+8）例行核对。遇到延期或日期冲突时，以该届会议对应赛道的官方公告为准。

<details>
<summary>字段说明 · 会议、英文期刊与中文期刊</summary>

| 字段 | 如何理解 |
| --- | --- |
| 会议 / 官网、开幕 / 地点 | 简称后的年份为举办年份。会议名链接到该届官网或征稿页；开幕日可包含教程或工作坊。 |
| 摘要截稿、全文截稿 | 分别对应摘要注册与完整稿件。多轮征稿按轮次列出。AoE 指 UTC−12。 |
| 通知及后续节点 | 按文字区分评审意见、作者回应（Rebuttal）、录用决定与终版（Camera-ready）。 |
| 简称 / 全称 | 沿用维护表中的缩写和英文刊名；无缩写时使用全称查找。 |
| CCF、CAAI | 原表采用中国计算机学会国际目录第七版（2026 年 3 月）和中国人工智能学会 2024 版目录。中文 CCF 栏采用 2025 年《计算领域高质量科技期刊分级目录》。 |
| 新锐 | 原表记录的 1–4 区分区；来源版本和学科口径待补。 |
| JCAR | 我们保留原表记录的 Low、Medium、Warning 标记，历史数据的版本和阈值待补。最新标记可在文末的 JCAR 网站查询。 |
| IF、年发文量 | 英文刊 IF 采用原表记录的 2025 年度期刊影响因子。年发文量以篇计，统计窗口及文献类型以原始来源为准，表中未逐刊注明。 |
| 审稿时间、变化记录 | 耗时为经验值；备注中的升降沿用原表与此前记录的比较，未注明基期。 |
| 知网 IF | 我们按中国知网复合影响因子整理，统计年份待补。与英文刊 IF 使用不同数据源。 |
| 北大核心、CSCD、EI 检索 | 依次记录《中文核心期刊要目总览》、中国科学引文数据库、EI Compendex 的收录情况。“是 / 否”取自本版工作簿。 |
| 卓越计划 | 中国科技期刊卓越行动计划入选类别，如领军期刊、梯队期刊。 |
| 空值 | — 表示该表未列值，可能涉及无独立环节、未收录、未知或该月无记录。TBD 表示待公布。 |

</details>

## 常用查询网站

我们用以下网站查找征稿信息、比对日期和查询期刊指标。核对会议截稿时，请先确认届次、赛道和时区；比较期刊指标时，请留意页面标注的年份和分区体系。

| 想查什么 | 查询入口 | 使用方式 |
| --- | --- | --- |
| 按简称找会议或期刊 | [MyHuiban（会伴）](https://www.myhuiban.com/) | 输入会议或期刊缩写，找到对应条目后查看征稿信息和官网入口。 |
| 哪些计算机会议即将截稿 | [Conference List](https://conferencelist.info/) | 在 Upcoming 中浏览近期会议，分别查看摘要截稿、全文截稿和通知日期。 |
| 按研究主题找会议 | [Resurchify](https://www.resurchify.com/) | 用研究方向或会议名称检索征稿信息，按届次找到目标会议。 |
| 期刊影响因子与分区 | [LetPub](https://www.letpub.com.cn/) | 按刊名或 ISSN 查询影响因子和分区，核对指标年份及所属学科。 |
| 期刊 JCAR 风险标记 | [JCAR 期刊预警指数查询](https://www.jcarindex.com/) | 按刊名查询当前风险标记，可与本指南记录的版本对照。 |
| Web of Science 收录与 On Hold 状态 | [Clarivate Master Journal List](https://mjl.clarivate.com/) | 用刊名或 ISSN 打开官方期刊条目，查看收录数据库及当前是否标有 On Hold（重新评估中）。 |
